# Prompting Fundamentals on Real Tasks v2 (FL-02)

This repository contains my submission for the **FL-02: Prompting Fundamentals on Real Tasks v2** assignment under the **General AI Fluency** track.

## Assignment Overview

The objective of this assignment is to demonstrate how prompt engineering techniques improve the quality of AI-generated outputs when applied to a real-world task.

For this assignment, I selected **Target Task 2 – GitHub Documentation** from my FL-01 AI Workflow Audit and iteratively improved prompts to generate professional GitHub documentation for my **Retail Sales & Inventory Analytics** project.

---

## Selected FL-01 Task

**Target Task:** GitHub Documentation

### Success Criteria

- Professional GitHub README
- Clear installation steps
- Technologies listed
- Proper Markdown formatting
- Easy-to-understand documentation

## Prompt Engineering Techniques Applied

The following techniques were applied sequentially:

1. Baseline (Naive Prompt)
2. Role Assignment
3. Context & Motivation
4. Few-Shot Examples
5. Output Structure
6. Step Decomposition

Each iteration demonstrates how prompt quality influences the final AI-generated output.

## Key Learnings

This assignment reinforced several important prompt engineering principles:

- Assigning a role improves tone and professionalism.
- Providing context helps the AI generate more relevant content.
- Few-shot examples improve consistency and formatting.
- Defining the expected output structure reduces ambiguity.
- Breaking complex tasks into smaller steps produces higher-quality results.
- Well-designed prompts have a greater impact on output quality than the choice of AI model alone.
