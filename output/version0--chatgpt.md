# 🛍️ Retail Sales & Inventory Analytics

> End-to-end Retail Sales & Inventory Analytics project using **MySQL,
> Python, Pandas, Scikit-learn, Power BI, and Excel**.

## 📌 Project Overview

This project analyzes retail sales, customers, products, and inventory
to uncover business insights through SQL analytics, exploratory data
analysis, customer segmentation, ABC inventory analysis, sales
forecasting, and interactive Power BI dashboards.

## 🎯 Objectives

-   Clean and prepare retail datasets
-   Perform SQL business analysis
-   Conduct exploratory data analysis (EDA)
-   Build RFM customer segmentation
-   Perform ABC inventory analysis
-   Forecast sales using Linear Regression
-   Build interactive Power BI dashboards

## 💡 Key Business Insights

-   Electronics generated the highest revenue.
-   High-value customers contribute a significant share of revenue.
-   Some products have high revenue but low margins.
-   Revenue varies across states.
-   Inventory value is concentrated in Class A products.
-   Monthly sales exhibit seasonal fluctuations.

## 🚀 Getting Started

``` bash
git clone https://github.com/yourusername/Retail-Sales-Inventory-Analytics.git
cd Retail-Sales-Inventory-Analytics
pip install -r requirements.txt
```

Import the SQL scripts into MySQL, run the notebooks, and open the
`.pbix` file in Power BI Desktop.
